# TYPE/TECH

TYPE/TECH은 여덟 가지 선택으로 가벼운 개발 기술 성향 결과를 보여주는 재미용 퀴즈입니다.

## 개인정보 보호 및 보안

답변과 결과는 브라우저 안에서 계산되며, 이전 화면 복원을 위해 현재 탭의 방문 기록 상태에 남을 수 있습니다. 서버나 `localStorage`에는 저장하지 않습니다. 결과 공유를 선택하면 결과 문구가 선택한 공유 앱 또는 클립보드로 전달됩니다. 화면 글꼴과 기술 로고는 프로젝트 안의 파일을 사용합니다.

자세한 내용은 [개인정보 보호 및 보안](./SECURITY.md)을 참고하세요.
