# Logo sources

The JavaScript, Python, Rust, and CSS SVG shapes are from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), downloaded on 2026-10-08. Python uses its familiar blue and yellow colors. Flutter uses a simplified, multicolor version of the same mark, colored to match the user-supplied Flutter SVG (light blue, cyan, and dark blue). The TypeScript SVG displays the exact image supplied by the user, cropped through its viewBox so the large white margins do not appear in the interface.
